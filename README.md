## English

HoMM III Companion is a streamer-side companion app for Heroes of Might and Magic III: Horn of the Abyss. It reads live game state from the running game process and sends it to the [HoMM III Companion Twitch Extension](https://dashboard.twitch.tv/extensions/yngq3ejk6b6z0838sjnxy5kz1k8eru-0.0.1), so viewers can inspect the streamer's current hero, army, artifacts, skills, spellbook, movement, spell points, and other live game details without cluttering the broadcast scene.

The project is designed for Heroes III PvP streams, where viewers want quick access to hero information while the streamer keeps the game screen clean.

The app was created exclusively for the Ukrainian Heroes III community [Stand with Ukraine - SWU](https://swuh3.com/).

### Features

- Connects to a running Heroes III / HotA game on the streamer's PC.
- Publishes the streamer's current game state to the companion Twitch Extension.
- Shows hero portraits, primary stats, morale, luck, experience, secondary skills, artifacts, army stacks, spellbook, and detailed info popups.
- Keeps viewer interaction separate from the streamer's OBS scene layout.

### Streamer App

Download the latest Windows streamer app from the [latest release](https://github.com/OneBrainCellTitan/HoMM-III-companion/releases/latest).

Basic setup:

1. Launch Heroes III / HotA.
2. Launch HoMM III Companion.
3. Connect your Twitch account.
4. Press the `Start` button.
5. Start streaming with the HoMM III Companion Twitch Extension enabled.

## Українською

HoMM III Companion - це додаток для стрімера, створений для Heroes of Might and Magic III: Horn of the Abyss. Він читає живий стан гри із запущеного процесу та передає його у [HoMM III Companion Twitch Extension](https://dashboard.twitch.tv/extensions/yngq3ejk6b6z0838sjnxy5kz1k8eru-0.0.1), щоб глядачі могли переглядати поточного героя стрімера, армію, артефакти, навички, книгу заклять, очки руху, очки мани та інші live-дані без зайвих шарів в OBS.

Проєкт орієнтований на Heroes III PvP-стріми, де глядачам важливо швидко дивитися інформацію про героя, а стрімеру - залишати основну картинку гри чистою.

Додаток був ексклюзивно створений для української Heroes III спільноти [Stand with Ukraine - SWU](https://swuh3.com/).

### Можливості

- Підключається до запущеної Heroes III / HotA на ПК стрімера.
- Передає поточний стан гри у companion Twitch Extension.
- Показує портрет героя, основні стати, мораль, удачу, досвід, навички, артефакти, армію, книгу заклять та детальні вікна інформації.
- Дозволяє глядачам взаємодіяти з інформацією, не змінюючи сцену стрімера в OBS.

### Додаток Для Стрімера

Завантажити актуальну Windows-версію можна на сторінці [останнього релізу](https://github.com/OneBrainCellTitan/HoMM-III-companion/releases/latest).

2. Запустити HoMM III Companion.
3. Підключити Twitch-акаунт.
4. Натиснути кнопку `Start`.
5. Почати стрім з увімкненим HoMM III Companion Twitch Extension.
